# Paid-pilot launch checklist

From Appendix M of the source plan. This is the go / no-go list for [Phase 16](../plan/phase-16-content-uat-pilot.md). Every box is ticked, or has a written reason, before the first paying family is invited.

## Business and legal

- [ ] Final prices approved
- [ ] Pilot duration and renewal wording approved
- [ ] Digital licence terms published
- [ ] Refund / cancellation terms published
- [ ] Privacy notice published
- [ ] Tax / GST / invoice process reviewed by an accountant or other professional
- [ ] Support contact and service expectation published

## Content

- [ ] 12 topic packs approved
- [ ] 2 flagship ebooks reviewed
- [ ] 3 bundles configured
- [ ] 15–20 free resources live
- [ ] 3 starter checks live
- [ ] First membership month complete for Classes 1–3
- [ ] Next-month buffer ready or in review
- [ ] All answer keys independently checked

## Website

- [ ] Homepage final
- [ ] Class / subject / topic pages final
- [ ] Free downloads work
- [ ] Shop and product previews are real
- [ ] Membership sample month visible
- [ ] Mobile navigation, search and checkout tested
- [ ] Help and policies reachable

- [ ] Webhook secret secured
- [ ] Live webhook endpoint verified
- [ ] Real-payment flow tested
