# SEO and content-discovery checklist

From Appendix J of the source plan. The public pages are built in [Phase 5](../plan/phase-05-public-library-ssr-search.md) and [Phase 6](../plan/phase-06-product-catalogue.md); the SEO system is completed in [Phase 12](../plan/phase-12-parent-hub-seo.md). Tick this list at the end of Phase 12 and again before launch.

## On every canonical page

- [ ] Unique title and H1
- [ ] Useful class / topic copy; no empty keyword pages
- [ ] Stable slug
- [ ] Breadcrumbs
- [ ] Canonical tag
- [ ] Body content present in the SSR HTML
- [ ] Meta description
- [ ] Open Graph / Twitter metadata
- [ ] Image alt text and dimensions

## Structured data

- [ ] Product / Offer JSON-LD for sellable items
- [ ] Article JSON-LD
- [ ] BreadcrumbList JSON-LD
- [ ] Organization JSON-LD

## Crawling and indexing

- [ ] XML sitemap
- [ ] Robots policy
- [ ] No staging indexing
- [ ] 404 / 410 / 301 rules
- [ ] No uncontrolled filter-index explosion
- [ ] Redirect on a changed slug

## Internal linking

- [ ] Internal links from class → subject → topic → resource
- [ ] Related resources and products
- [ ] No important resource is an orphan

## Performance

- [ ] Mobile performance

## Launch

- [ ] Search Console verification
- [ ] Sitemap submission
- [ ] Index coverage monitoring
