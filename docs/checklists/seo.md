# SEO and content-discovery checklist

From Appendix J of the source plan. The public pages are built in [Phase 5](../plan/phase-05-public-library-ssr-search.md) and [Phase 6](../plan/phase-06-product-catalogue.md); the SEO system is completed in [Phase 12](../plan/phase-12-parent-hub-seo.md). Tick this list at the end of Phase 12 and again before launch.

## On every canonical page

- [x] Unique title and H1
- [x] Useful class / topic copy; no empty keyword pages
- [x] Stable slug
- [x] Breadcrumbs
- [x] Canonical tag
- [x] Body content present in the SSR HTML
- [x] Meta description
- [x] Open Graph / Twitter metadata
- [x] Image alt text and dimensions

## Structured data

- [x] Product / Offer JSON-LD for sellable items
- [x] Article JSON-LD
- [x] BreadcrumbList JSON-LD
- [x] Organization JSON-LD

## Crawling and indexing

- [x] XML sitemap
- [x] Robots policy
- [x] No staging indexing
- [x] 404 / 410 / 301 rules
- [x] No uncontrolled filter-index explosion
- [x] Redirect on a changed slug

## Internal linking

- [x] Internal links from class → subject → topic → resource
- [x] Related resources and products
- [x] No important resource is an orphan

## Performance

- [x] Mobile performance

## Launch

- [ ] Search Console verification
- [ ] Sitemap submission
- [ ] Index coverage monitoring
